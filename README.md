# Мультяшные гонки с разрушениями

**Игра для телефона (Android APK)** — 3D-гонки в мультяшном стиле: смесь **FlatOut** (таран и разрушения) и **Crash Team Racing** (арена, бонусы, оружие).

> Управление рассчитано на **тачскрин** (альбомная ориентация). Клавиатура — только запасной вариант на ПК.

- Репозиторий: https://github.com/artemkz147-ship-it/cartoon-crash-racer  
- APK: вкладка [Releases](https://github.com/artemkz147-ship-it/cartoon-crash-racer/releases) или артефакт Actions `cartoon-crash-racer-apk`

## Установка APK на телефон (sideload)

1. Скачайте `cartoon-crash-racer-debug.apk` из [Releases](https://github.com/artemkz147-ship-it/cartoon-crash-racer/releases) или из последнего успешного GitHub Actions.
2. На Android: **Настройки → Безопасность** — разрешите установку из неизвестных источников / «Установка неизвестных приложений» для браузера/файлового менеджера.
3. Откройте скачанный `.apk` и установите.
4. Запустите **«Мультяшные гонки»**. Держите телефон **горизонтально** (ландшафт).

Пакет: `com.artemkz.cartooncrashracer`

## Сенсорное управление (схема словами)

```
┌──────────────────────────────────────────────┐
│  [HUD здоровье…]          ⏸ пауза   [круг…] │
│                                              │
│                                              │
│  ○ джойстик РУЛЬ              🔥 огонь       │
│  ◀     ▶                      ↺ респаун      │
│                               ⚡     ▲ ГАЗ   │
│                               ▼ТОРМ          │
└──────────────────────────────────────────────┘
```

| Зона | Кнопки | Действие |
|------|--------|----------|
| **Слева** | Виртуальный джойстик | Руль (влево/вправо) |
| **Слева** | ◀ ▶ | Доп. педали руля (большие) |
| **Справа** | ▲ ГАЗ | Ускорение вперёд |
| **Справа** | ▼ ТОРМ | Тормоз / назад |
| **Справа** | ⚡ | Ускорение (nitro), если есть заряд |
| **Справа** | 🔥 | Стрельба (после подбора оружия) |
| **Справа** | ↺ | Мягкий респаун, если застряли |
| **Сверху** | ⏸ | Пауза |

На стартовом экране: **«НАЖМИ, ЧТОБЫ СТАРТ»**. Подсказки с клавиатуры на телефоне скрыты.

Мультитач поддерживается: можно одновременно жать газ + руль + огонь.

## ПК (браузер, опционально)

```bash
npm install
npm run dev
```

| Клавиши | Действие |
|--------|----------|
| W / ↑ | Газ |
| S / ↓ | Назад |
| A / ← · D / → | Руль |
| Space / Shift | Ускорение |
| ЛКМ / F | Стрельба |
| R | Респаун |
| P / Esc | Пауза |

## Сборка Android (Capacitor)

Стек: Vite + Three.js + cannon-es + **Capacitor 6** → Android WebView.

```bash
npm install
npm run build
npx cap sync android
# на машине с JDK 17 + Android SDK:
cd android && ./gradlew assembleDebug
```

Готовый debug APK: `android/app/build/outputs/apk/debug/app-debug.apk`

CI: `.github/workflows/android.yml` — JDK 17, Android SDK, `assembleDebug`, артефакт `cartoon-crash-racer-apk`; на тег `v*` APK прикрепляется к релизу.

## Что в игре

- Овальная арена, игрок + 2 агрессивных ИИ
- Таран с уроном, лёгкий screen-shake, крупные обломки
- Яркие бонусы: оружие (ракета), броня, ускорение
- Гонка на 3 круга, пауза, стартовый экран на русском
- Landscape lock в AndroidManifest
