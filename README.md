# Мультяшные гонки с разрушениями

**Полноценный мобильный аркадный пакет** (Android APK) — мультяшный **FlatOut × Crash Team Racing**: карьера, быстрая гонка, дерби, гараж, разрушения.

> Версия **1.0.0** — полный контент, не демо-овал.  
> Графика процедурная (Three.js) → APK лёгкий по размеру, по ощущениям — инди-аркада.

- Репозиторий: https://github.com/artemkz147-ship-it/cartoon-crash-racer  
- APK: [Releases](https://github.com/artemkz147-ship-it/cartoon-crash-racer/releases) · артефакт Actions `cartoon-crash-racer-apk`

Пакет: `com.artemkz.cartooncrashracer` · **1.0.0** (подписанный release для sideload)

## Контент v1.0

| Раздел | Количество |
|--------|------------|
| **Трассы** | **8** тематических (город, пустыня, снег, завод-восьмёрка, стадион, лес, доки, вулкан/лава) |
| **Карьера** | **12 кубков** с прогрессией и медалями |
| **Машины** | **8** уникальных (статы: скорость / руль / броня / оружие) |
| **Режимы** | Карьера · Быстрая гонка · Дерби (**2 арены**) · Гараж · Настройки |
| **ИИ** | до **7** соперников с именами и характером |
| **Разрушения** | ящики, барьеры, **взрывные бочки** с цепной реакцией, масло, буст-пады, лава |

### Режимы

1. **Карьера** — 12 кубков. Финиш в топ-N открывает следующий. Медаль (золото/серебро/бронза) = место + очки разрушений. Прогресс в `localStorage`.
2. **Быстрая гонка** — выбор любой из 8 трасс и числа кругов.
3. **Дерби** — две арены, последний выживший / очки за разгром.
4. **Гараж** — выбор машины, полоски статов; открытие за медали/кубки.

### Почему APK «маленький»

Capacitor + WebView + **процедурная** геометрия/текстуры (без гигабайт сканов). Это нормально для аркады такого типа — контент в системах и разнообразии, не в весе файлов.

## Установка APK (sideload)

1. Скачайте **`cartoon-crash-racer.apk`** (signed release) из [Releases / v1.0.0](https://github.com/artemkz147-ship-it/cartoon-crash-racer/releases/tag/v1.0.0).
2. Android → разрешите установку из этого источника (браузер / «Файлы»).
3. Если была старая debug-сборка — **удалите** её (другая подпись) и поставьте v1.0.0 заново.
4. Запуск в **альбомной** ориентации.

## Стек

Vite · Three.js · cannon-es · Capacitor 6 → Android WebView.

```bash
npm install
npm run build
npx cap sync android
cd android && ./gradlew assembleRelease
```

CI собирает **подписанный release APK** на push и на тег `v*`.
