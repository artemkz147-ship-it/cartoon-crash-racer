# Мультяшные гонки с разрушениями

Браузерный прототип 3D-гонок в мультяшном стиле: смесь **FlatOut** (таран и разрушения) и **Crash Team Racing** (арена, бонусы, оружие).

> Это **прототип**: упрощённая физика, простые ИИ-соперники, процедурные low-poly модели без внешних ассетов. Цель — играбельный цикл, а не готовый продукт.

## Стек

- [Vite](https://vitejs.dev/)
- [Three.js](https://threejs.org/) — графика
- [cannon-es](https://github.com/pmndrs/cannon-es) — физика

## Установка и запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

Сборка и предпросмотр:

```bash
npm run build
npm run preview
```

## Управление

| Клавиши | Действие |
|--------|----------|
| **W / ↑** | Газ |
| **S / ↓** | Назад |
| **A / ←**, **D / →** | Руль |
| **Space / Shift** | Ускорение (если есть заряд) |
| **ЛКМ / F** | Стрельба (после подбора оружия) |
| **R** | Мягкий респаун, если застряли |

На экране подсказки на русском.

## Что есть в прототипе

- Овальная арена с бордюрами и стенами
- Игрок + 2 ИИ-соперника (яркие мультяшные машины)
- Таран машин с уроном по здоровью
- Разрушаемые ящики, бочки и барьеры → обломки с физикой
- Бонусы на трассе: **оружие** (самонаводящаяся ракета), **броня**, **ускорение**
- Здоровье, броня, респаун после «смерти»
- Камера от третьего лица
- HUD на русском: здоровье, броня, оружие, круг/время, место
- Гонка на 3 круга
- Индикатор низкого здоровья на HUD

## Честный scope

- ИИ едет заметно, но «криво» — это задумано для прототипа
- Нет сетевой игры, меню настроек, звуков и сложных треков
- Модели только процедурные (без скачивания 3D с внешних сервисов)
- Баланс урона/скорости черновой
