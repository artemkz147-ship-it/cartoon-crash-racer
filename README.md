# Мультяшные гонки с разрушениями

**Игра для телефона (Android APK)** — 3D-гонки в мультяшном стиле: смесь **FlatOut** (таран и разрушения) и **Crash Team Racing** (арена, бонусы, оружие).

> Версия **0.3.0** — крупное обновление графики, физики и геймплея.  
> Управление рассчитано на **тачскрин** (альбомная ориентация). Клавиатура — запасной вариант на ПК.

- Репозиторий: https://github.com/artemkz147-ship-it/cartoon-crash-racer  
- APK: вкладка [Releases](https://github.com/artemkz147-ship-it/cartoon-crash-racer/releases) или артефакт Actions `cartoon-crash-racer-apk`

## Установка APK на телефон (sideload)

1. Скачайте `cartoon-crash-racer-debug.apk` из [Releases](https://github.com/artemkz147-ship-it/cartoon-crash-racer/releases) или из последнего успешного GitHub Actions.
2. На Android: **Настройки → Безопасность** — разрешите установку из неизвестных источников / «Установка неизвестных приложений» для браузера/файлового менеджера.
3. Откройте скачанный `.apk` и установите.
4. Запустите **«Мультяшные гонки»**. Держите телефон **горизонтально** (ландшафт).

Пакет: `com.artemkz.cartooncrashracer` · версия `0.3.0`

## Сенсорное управление

```
┌──────────────────────────────────────────────┐
│  [HUD…]     🔊 mute   ⏸ пауза        [круг…] │
│                                              │
│  ○ джойстик РУЛЬ              🔥 огонь       │
│  ◀     ▶                      ↺ респаун      │
│                               ⚡     ▲ ГАЗ   │
│                               ▼ТОРМ          │
└──────────────────────────────────────────────┘
```

| Зона | Кнопки | Действие |
|------|--------|----------|
| **Слева** | Виртуальный джойстик | Руль (влево/вправо) |
| **Слева** | ◀ ▶ | Доп. педали руля |
| **Справа** | ▲ ГАЗ / ▼ ТОРМ | Газ / тормоз |
| **Справа** | ⚡ | Ускорение (nitro) |
| **Справа** | 🔥 | Стрельба (ракета / мины / дробь) |
| **Справа** | ↺ | Мягкий респаун |
| **Сверху** | ⏸ / 🔊 | Пауза / звук |

Мультитач: газ + руль + огонь одновременно.

## Что нового в 0.3.0

- **Графика:** небо-купол с градиентом, клетчатый газон, асфальт с разметкой, билборды и здания на фоне
- **Машины:** капот, спойлер, фары, арки колёс, тень-пятно, пузырь брони
- **Трасса:** банки на поворотах, рампы/трамплины, шорткат с ломаемыми стенами, плотные кучи пропов
- **Эффекты:** пыль, дым буста, искры при таране, взрывы, следы шин, шлейф ракет
- **Управление:** дрифт-слайд, весомый таран, FOV-punch на бусте, screen-shake
- **Оружие:** ракеты с AoE + мины и дробовик на альтернативных бонусах
- **ИИ:** лёгкий rubber-band, сбор бонусов, стрельба и таран
- **Аудио:** процедурный Web Audio (мотор, удары, пикапы) + кнопка mute
- **Экраны:** стартовое меню с подсказкой, экран результатов после финиша
- **Производительность:** пул частиц, лимит обломков, на мобиле — blob-тени вместо shadow maps

## ПК (браузер)

```bash
npm install
npm run dev
```

| Клавиши | Действие |
|--------|----------|
| W / ↑ | Газ |
| S / ↓ | Назад |
| A / ← · D / → | Руль |
| Space / Shift | Ускорение |
| ЛКМ / F | Стрельба |
| R | Респаун |
| P / Esc | Пауза |

## Сборка Android (Capacitor)

Стек: Vite + Three.js + cannon-es + **Capacitor 6** → Android WebView.

```bash
npm install
npm run build
npx cap sync android
cd android && ./gradlew assembleDebug
```

CI: `.github/workflows/android.yml` — на push/тег `v*` собирает APK и прикладывает к релизу.
